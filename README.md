# RamLS - Swapping a RAM 1500 2nd gen with LQ4
We're swapping a 1999 Ram 1500 Sport with the 5.9L Magnum Automatic to use an 6.0L LQ4 out of a 2002 Yukon Denali with a small street Cam.

- 2002 Yukon Denali is the donor vehicle, so parts should be for that vehicle

## Ram specs

- 7290 Rear diff U-joint size
